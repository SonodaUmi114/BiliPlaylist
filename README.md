# BiliPlaylist

一个运行在哔哩哔哩（B 站）网页端的**播放列表增强工具**，以 **Chrome 扩展（Manifest V3）** 形式实现。

> 状态：**v1.2.3**——v1.2 新增「侧边栏分组/文件夹」，v1.2.1 组头增加播放按钮，v1.2.2 修复分P断点续播，v1.2.3 修复分P结束误判；全部功能已实测通过，`npm test` 48 项断言通过。详细开发约定见 [agents.md](agents.md)。

## 功能（v1.0）

- **多选批量加入**：在 UP 主空间投稿页（`space.bilibili.com/{uid}/video`）与空间内搜索页（`space.bilibili.com/{uid}/search?keyword=...`）多选视频，批量加入播放列表
- **播放列表侧边栏**：右下角热区按钮簇（侧边栏/加入/多选）打开；条目显示视频名称、UP主名、分P进度（如 1/11）、当前分P播放时间 `hh:mm:ss`，播放按钮 ▶（新标签页）、删除、头部全局刷新、已播完标记；动态页 `t.bilibili.com` 同样有热区侧边栏
- **排序 + 查重**：多选批量加入按发布日期升序（日期早的在前、先播放）；视频页单个加入追加到列表末尾；支持拖拽排序；按 bvid 去重（重复不添加并提示）
- **侧边栏排序模式（v1.1）**：头部「⇅ 排序」进入；多选（单击 / Shift 范围 / Ctrl 单独 / 全选）+ **手动分组拖拽**（含落点指示线）+ **按发布日期升/倒序自动排序**（仅对选中视频生效、原位置内重排、缺失日期先补全）+ **撤销上一步**；排序结果持久化
- **侧边栏分组/文件夹（v1.2）**：排序模式选中视频点「成组」→ 归为一组；文件夹标签**可重命名 / 收起展开**（默认收起、每次加载重置；收起显示成员数与首条摘要，排序模式下组头带选中勾选指示，点组头切换选中/取消该组成员）；组头 **▶ 播放按钮（v1.2.1）** 播放组内第一个视频、从断点续播；组内排序**组间不排**；支持**拖进/移出文件夹、拖文件夹改位置、取消分组**
- **分P连播**：分P内无刷新自动切换下一分P；全部分P播完自动跳转列表下一个视频
- **播放器窗口模式记忆**：记住 默认 / 网页全屏 / 全屏，切换视频刷新后自动恢复
- **播放进度记忆**：记住每个视频的播放进度（含分P位置），下次继续观看
- **白灰简约 UI**：符合 B 站网页版风格，Shadow DOM 隔离，不污染页面样式

## 安装（开发模式）

1. 打开 Chrome 或 Edge，访问 `chrome://extensions`
2. 开启右上角"开发者模式"
3. 点击"加载已解压的扩展程序"，选择本项目根目录

## 开发

- 开发约定、目录结构、B 站接口要点详见 [agents.md](agents.md)
- **改动生效流程**：扩展页点击该扩展的"重新加载" → 刷新 B 站页面（两步缺一不可）
