# 功能规格：播放列表侧边栏 —— 排序 / 多选排序

> 状态：**方案已定稿（待实现）**。本文档记录该功能的需求、选定方案与决策过程，供后续开发与追溯。
> 关联项目约定见 `agents.md`；实现集中在 `src/ui.js` 侧边栏部分。

---

## 1. 目标

在**播放列表侧边栏**内新增**排序（编辑）模式**，能力包含：`多选 / Shift 范围 / Ctrl 单独 / 全选`、`手动分组拖拽`、`按发布日期自动排序（升/倒序）`、`撤销上一步`。

**作用范围**：仅侧边栏（`www / space / t` 三域站内，`ui.js` 侧边栏），与空间页「多选加入」互不影响。

## 2. 交互规格（已确认）

### 2.1 进入方式
- 侧边栏头部新增**「排序」按钮**（⇅）。点击进入排序模式，按钮高亮为 B 站蓝。
- 排序模式下显示**排序工具栏**（位于头部下方，侧边栏内）。退出（「完成」按钮）后恢复普通模式。

### 2.2 排序工具栏
- **已选 N**（数量实时更新）
- **全选**：一键选中当前列表全部
- **撤销**：回退最近一次 排序 / 分组拖拽 / 单项移动
- **自动排序方向下拉**：`升序↑`（默认） / `倒序↓`
- **自动排序**：按 `pubdate` 排序（详见 §2.5）
- **完成**：退出排序模式

### 2.3 选中逻辑
- **单击某项** = 仅选中该视频（清除其它选中），并设为 Shift 锚点。
- **Shift + 点击** = 范围多选（含两端）：例如 1..8，先点 2 再 Shift+点 6 → 选中 `2,3,4,5,6`。
- **Ctrl / ⌘ + 点击** = 单独增删该视频（不清除其它），并设为锚点。
- **全选 / 清空**：批量设置/清空选中集合。

### 2.4 手动分组拖拽
- 选中这批视频（可**连续**、也可**不连续**）后，按住任一选中项拖动到目标位置；拖拽过程显示**落点指示线**（在两条目之间高亮插入点）。
- 松手后：整组按**原相对顺序**移动到目标位置，未选中项保持相对顺序（其间的空位被压缩）。
- 例：`1 2 3 4 5 6 7 8`，选中 `3,4,5,6` 拖到 `1` 之前 → `3 4 5 6 1 2 7 8`。
- **仅选中 1 个** = 退化为普通单项移动。
- **拖动未选中项** = 视为「仅选中它再移动」。
- 非排序模式：保留原有**单条拖拽**行为（`moveItem`）。

### 2.5 自动排序
- 按**发布日期 `pubdate`** 的 **升序 / 倒序**（工具栏方向下拉决定）。
- **仅对选中的视频生效**，且采用**「在原位置内重排」**语义：未选中项位置完全不变；只把选中子集按日期排好，放回它们各自原来的位置（slot）。全选即为整体排序。
- **缺失 `pubdate`**：排序前先调用 `view` 接口补全（复用 `backfillAndResort` 思路，仅针对选中项、200ms 节流）；仍补不全者**放末尾**（升序、倒序均放末尾）。
- 排序完成保留选中状态（按 bvid），便于继续操作。

### 2.6 撤销
- 维护快照栈（最近 ≤20 个排序/拖拽前的列表快照，深拷贝）。「撤销」回退上一步并重渲。
- 覆盖：自动排序、分组拖拽、单项移动。

### 2.7 边界 / 约束
- 排序模式是**临时编辑态**：进入播放页自动退出（跨页面不保持）。
- 空列表 / 单条 / 未选中时点「自动排序」：给出提示，不做非法操作。
- 排序/拖拽不影响条目字段：分P进度、播放时间、已看完标记、窗口模式。
- **UI 风格**：白灰简约、不用粉色；强调色 B 站蓝 `#00aeec`；排序模式 UI 全部在**侧边栏 Shadow DOM 内**（勾选指示与工具栏），不注入页面 DOM、不污染页面样式。
- 排序结果持久化到 `biliplaylist:list`；跨子域经 `chrome.storage.local` 同步一致。

## 3. 开发步骤（阶段）
- **A 状态与数据**：`sortMode` / `sortDirection` / `anchorIndex` / `biliSel`(Set<bvid>) / `undoStack` / `dropLine`。
- **B 入口与工具栏**：头部「排序」按钮 + 排序工具栏；`renderList` 渲染勾选、`refresh` 保留选中。
- **C 选中逻辑**：单击 / Shift 范围 / Ctrl 单独增删 / 全选清空。
- **D 分组拖拽**：`moveSelectionTo` 分组移动算法 + 落点指示线；普通模式仍用 `moveItem`。
- **E 自动排序**：`autoSortSelected` 原 slot 内重排 + 先补全缺失日期，未补齐放末尾。
- **F 撤销**：`pushUndo` / `undo` 快照栈。
- **G 手动测试**：视频页/空间页侧边栏全流程 + 边界 + 白灰风格 + 普通单条拖拽回归。

## 4. 决策记录（已与用户确认）
- 自动排序「仅对选中生效」的放置语义：**在原位置内重排**（未选中项位置不变）。
- 缺失 `pubdate`：**排序前先用接口补全**（未补齐放末尾）。
- 纳入的优化项：**拖拽落点指示线**、**Ctrl/⌘+点击单独多选**、**自动排序前补全发布日期**、**撤销上一步**（四项全选）。
